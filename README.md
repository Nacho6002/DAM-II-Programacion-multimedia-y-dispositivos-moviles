# Programación multimedia y dispositivos móviles - Proyectos DAM

Repositorio con una selección de mis proyectos más representativos del módulo de **Programación multimedia y dispositivos móviles** del ciclo formativo de **Desarrollo de Aplicaciones Multiplataforma (DAM)**.

## Sobre este repositorio
Aquí recopilo proyectos académicos centrados en desarrollo móvil, interfaces Android, consumo de APIs y almacenamiento local de datos.

He seleccionado los trabajos que mejor representan mi aprendizaje en el módulo, priorizando funcionalidad, estructura y presentación del proyecto.

## Proyecto incluido

### Weather App Android
Aplicación Android desarrollada en Java que integra:
- búsqueda de información meteorológica mediante API
- almacenamiento local con Room
- arquitectura con ViewModel y LiveData
- lista de ciudades guardadas con RecyclerView
- carga de iconos remotos con Glide

## Tecnologías trabajadas
- Java
- Android Studio
- Room
- Retrofit
- LiveData
- ViewModel
- Glide
- XML

## Estructura del repositorio
- `weather-app-android/`

## Objetivo
Mostrar de forma clara y ordenada uno de mis proyectos más representativos del módulo, combinando desarrollo móvil, consumo de APIs y persistencia local.
