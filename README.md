## 📖 Sobre este repositorio

Aquí recopilo una selección de mis proyectos más representativos del módulo de **Programación multimedia y dispositivos móviles**, centrados en:

- desarrollo de aplicaciones Android
- interfaces móviles
- consumo de APIs externas
- persistencia local de datos
- arquitectura básica en aplicaciones móviles

He seleccionado los trabajos que mejor representan mi aprendizaje en el módulo, priorizando funcionalidad, estructura y presentación del proyecto.

---

## 🚀 Proyecto incluido

### 🌦️ Weather App Android
Aplicación Android desarrollada en **Java** que integra información meteorológica obtenida desde una API externa y almacenamiento local con Room.

**Incluye:**
- búsqueda de información meteorológica mediante API
- almacenamiento local de ciudades
- arquitectura con ViewModel y LiveData
- lista de ciudades guardadas con RecyclerView
- carga de iconos remotos con Glide

📂 Carpeta del proyecto: `weather-app-android/`
