## 📱 Descripción

**Weather App Android** es una aplicación móvil que permite buscar ciudades mediante la API de **OpenWeather**, mostrar información meteorológica en pantalla y guardar resultados localmente en una base de datos **Room**.

El proyecto combina consumo de API, persistencia local y una interfaz sencilla pensada para mostrar resultados de forma clara y rápida.

---

## ✨ Funcionalidades

- Búsqueda de ciudades en la API de OpenWeather
- Visualización de temperatura, descripción e icono del clima
- Almacenamiento local de ciudades con Room
- Listado de ciudades guardadas mediante RecyclerView
- Navegación entre pantalla principal y buscador

## 🧠 Arquitectura y enfoque

El proyecto combina varios elementos habituales del desarrollo Android:

- **persistencia local** mediante Room
- **consumo de API REST** con Retrofit
- **gestión del estado** con ViewModel y LiveData
- **carga de imágenes remotas** con Glide
- **interfaz XML** con Activities y RecyclerView

## 🔐 Nota importante

Para ejecutar correctamente la aplicación es necesario configurar una **API key propia de OpenWeather**.

Por seguridad, la clave personal no se incluye en el repositorio público.
