# Weather App Android

Proyecto académico del módulo de **Programación multimedia y dispositivos móviles** desarrollado para Android.

## Descripción
Aplicación Android que permite buscar ciudades mediante la API de OpenWeather, mostrar información meteorológica y guardar resultados localmente en una base de datos Room.

## Funcionalidades
- Búsqueda de ciudades en la API de OpenWeather
- Visualización de temperatura, descripción e icono del clima
- Almacenamiento local de ciudades con Room
- Listado de ciudades guardadas mediante RecyclerView
- Navegación entre pantalla principal y buscador

## Tecnologías utilizadas
- Java
- Android Studio
- Room
- LiveData
- ViewModel
- Retrofit
- Glide
- XML

## Notas
Para ejecutar correctamente la aplicación es necesario configurar una API key propia de OpenWeather.

Proyecto realizado con fines académicos.
